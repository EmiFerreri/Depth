# Changelog

## 0.2.0 — Flow foundation

- Connected modular Canvas game, fixed 120 Hz simulation and safe local server.
- Flow, Sprint, UTC Daily and 100-sector Campaign modes.
- Four repeating route patterns, curve rides, infinite jump, dash, shooting and drones.
- Functional boost rings, shield, low gravity, combo, checkpoints and result screen.
- Local best score/time records with separate practice and control modes.
- Responsive menu/HUD, touch controls, automatic focus-loss pause, reduced motion,
  synthesized sound effects, fullscreen and keyboard dialogs.
- Engine regression tests, all-source syntax checks and optional browser smoke.
- Targeted restart/input/score fixes in legacy 007/007B and RNG/input repairs in 100.
- Source audit, architecture and human playtest documentation.

Browser and device sign-off remains pending; see the audit. No Actions workflow added.
